# @lavamoat/dictionary

[CSpell][] dictionary definitions for the LavaMoat Project.

## Installation

```sh
npm install @lavamoat/dictionary -D
```

## Usage

In your [CSpell configuration file](https://cspell.org/docs/Configuration) add the following:

<dl>
<dt>JSON</dt>
<dd>

```json
{
  "import": "@lavamoat/dictionary"
}
```

</dd>

<dt>YAML</dt>
<dd>

```yaml
import: '@lavamoat/dictionary'
```

</dd>
</dl>
